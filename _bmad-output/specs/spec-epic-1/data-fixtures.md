# Data Fixtures

Epic 1 starts by making the Case A data available for tooling and tests.

Expected source paths:

- `cases/expense/seed/claims.csv`
- `cases/expense/seed/line_items.csv`
- `cases/expense/seed/employees.csv`
- `cases/expense/seed/limits.csv`
- `cases/expense/eval/labelled.csv`

The seed files provide claim, line item, employee, and limit context. The labelled examples provide the acceptance basis used by later policy-review work; Epic 1 only needs them present and loadable.
